# Uptown Assets: ระบบทำวิดีโอ TikTok สำหรับอสังหาริมทรัพย์

ระบบนี้ใช้ Claude Code ทำวิดีโอแนวตั้ง (9:16) สำหรับโพสต์ขายหรือเช่าทรัพย์บน TikTok ตั้งแต่อ่านข้อมูลประกาศ วางเรื่อง ทำเสียงพากย์ ไปจนถึงตัดต่อเป็นไฟล์ MP4 พร้อมโพสต์
งานแบ่งให้ AI หลายตัวทำตามหน้าที่ โดยมี **director** (ผู้กำกับ) เป็นตัวที่คุยกับเราและสั่งงานตัวอื่น

## ทีมงาน

| ชื่อ | ไฟล์ | หน้าที่ |
|---|---|---|
| **director** (role) | [.claude/roles/director.md](.claude/roles/director.md) | ผู้กำกับ เป็น role เริ่มต้นของโปรเจกต์ คุยกับเราเป็นภาษาไทย ถามข้อมูลที่ขาด วาง treatment และ shot list เขียน copy กับ caption สั่งงาน agent ด้านล่าง แล้วตรวจผลงานก่อนรายงาน |
| **brief** (agent) | [.claude/agents/brief.md](.claude/agents/brief.md) | อ่านข้อมูลประกาศ ตรวจรูปและคลิปทุกไฟล์ แยกตามห้อง ดึงข้อเท็จจริงของทรัพย์ แล้วเขียน `brief.md` (ความพร้อม, treatment ร่าง, สคริปต์เสียงพากย์, brief สำหรับ editor) |
| **retouch** (agent) | [.claude/agents/retouch.md](.claude/agents/retouch.md) | แต่งรูปก่อนทำวิดีโอ แบบฟรีด้วย ffmpeg (ดัดภาพเอียง ปรับแสงและสี ปรับโทนให้เข้ากัน ลดนอยส์ เบลอหน้าคนและป้ายทะเบียน) และแบบใช้เครดิต Magnific (ลบของรก จัดเฟอร์นิเจอร์เสมือน เปลี่ยนท้องฟ้า ขยายภาพ) ตรวจทุกรูปเทียบกับต้นฉบับ แล้วบันทึกไว้ใน `output/retouched/` |
| **voice-kanya** (agent) | [.claude/agents/voice-kanya.md](.claude/agents/voice-kanya.md) | ทำเสียงพากย์ภาษาไทยด้วยเสียง Kanya ของ macOS (`say`) ทำงานบนเครื่องทั้งหมด ฟรี แต่เสียงจะออกแนวหุ่นยนต์ ได้ไฟล์ `voiceover.wav` ที่ตรงกับไทม์ไลน์วิดีโอ |
| **editor-magnific** (agent) | [.claude/agents/editor-magnific.md](.claude/agents/editor-magnific.md) | ขยายภาพให้คมขึ้น (Magnific Precision) แล้วเปลี่ยนรูปเป็นคลิปเคลื่อนไหวด้วย AI ของ Magnific (image-to-video เช่น Kling) ประเมินเครดิตก่อนและใช้ไม่เกินงบที่ director ให้ ตรวจภาพที่ขยายและทุกคลิปเทียบกับรูปต้นฉบับว่าไม่มีของงอก หาย หรือบิดเบี้ยว แล้วดาวน์โหลดมาไว้ให้ editor ตัดต่อ (ไม่ได้ตัดวิดีโอฉบับสุดท้ายเอง) |
| **editor** (agent) | [.claude/agents/editor.md](.claude/agents/editor.md) | ตัดต่อด้วย HyperFrames (เขียนวิดีโอเป็น HTML แล้วเรนเดอร์) ทำวิดีโอ 9:16 (1080×1920, 30 วินาที) สำหรับ Reels, TikTok, Shorts และทำ 16:9 / 1:1 เพิ่มเมื่อขอ ใส่ Ken Burns, ตัวหนังสือเคลื่อนไหว, caption, การ์ด, โลโก้ และ end card แล้วใช้ ffmpeg ใส่เสียงพากย์กับเพลง ตรวจไฟล์ก่อนส่ง |

## ขั้นตอนการทำวิดีโอ

1. **ส่งข้อมูลทรัพย์**: เปิดเซสชันในโปรเจกต์นี้ (role `director` ถูกเลือกให้อัตโนมัติ) แล้วส่งลิงก์ประกาศ uptownassets.com หรือส่งข้อความประกาศกับรูปและคลิปของเราเอง ระบบจะสร้างโฟลเดอร์ `listings/<รหัส>-<ชื่อทรัพย์>/assets/` ให้
   - หนึ่งเซสชันทำหนึ่งทรัพย์ ถ้าส่งทรัพย์ใหม่มาระหว่างที่วิดีโอเดิมยังไม่เสร็จ director จะเปิดเซสชันใหม่ให้ทรัพย์นั้นแล้วทำของเดิมต่อ (แก้หรือตัดใหม่ทรัพย์เดิมทำในเซสชันเดิมได้)
2. **เลือกสไตล์และการจัดวาง**: director ถามด้วยกล่องคำถามของแอปให้เลือกสไตล์จาก [STYLES.md](STYLES.md) แบบที่เหมาะกับทรัพย์ขึ้นก่อนพร้อมป้าย "(แนะนำ)" กดสไตล์ครั้งเดียวจบ ไม่ต้องกด Enter (อยากปรับเพิ่ม พิมพ์ในช่อง Other)
   - ในกล่องเดียวกันมีคำถามการจัดวางข้อความ (ส่งภาพ [brand/layouts/layouts_all.png](brand/layouts/layouts_all.png) ให้ดูก่อน): **A ข้อความกลางจอ** (โลโก้ชิดซ้าย ชื่อโครงการข้างโลโก้), **B ข้อความบนและล่าง** (ไม่มีโลโก้ ชื่อภาพด้านบน ข้อมูลด้านล่าง ชิดซ้ายทั้งหมด), **C ข้อความล่าง** (ด้านบนเหมือน A) ไม่เลือกใช้ C สไตล์การ์ดข้อมูลมีเลย์เอาต์ของตัวเองจึงไม่ถาม ทั้งสามแบบวางข้อความชิดขอบบนและล่าง (y 80–1840) จึงอาจซ้อนกับปุ่มหรือแคปชันของแอปบางส่วน รายละเอียดใน [STYLES.md](STYLES.md) หัวข้อ "การจัดวางข้อความ"
   - **มาตรฐาน** (เป็นกันเอง) · **เรียบหรู** (ช้า สงบ) · **เดินชมห้อง** (คลิปเดินชมห้อง แฟลชอุ่น เพลงอย่างเดียว) · **การ์ดข้อมูล** (รูปในกรอบบนพื้นเบลอ หัวข้อเป็นหมวดพร้อมชิป ป้ายราคามุมขวาบน มีเสียงบรรยาย)
   - ทุกสไตล์ยาว 30 วินาที เล่าตามโครงเรื่องเดียวกัน: hook 0–3 วิ (Hero Shot + จุดขาย + ราคา) → จุดขายเรียงจากแรงสุด (ช็อตเร็ว-ช้าตามความสำคัญ) → ส่วนกลาง/ใกล้ → ราคาอีกครั้ง → Call to Action 27–30 วิ ([STYLES.md](STYLES.md))
   - สไตล์กำหนดโทนภาษา ความยาว จังหวะช็อต ทรานสิชัน หน้าตาตัวหนังสือ ความเร็วพากย์ อารมณ์เพลง และสไตล์ staging
   - แต่ละสไตล์มีเพลงบรรเลงประจำใน `brand/music/` (standard, calm, walk .mp3 สร้างด้วย AI ของ Magnific; การ์ดข้อมูลใช้ walk.mp3 ไปก่อน) ใช้เมื่อทรัพย์ไม่มีเพลงของตัวเองใน `assets/`
   - ถ้าบอกสไตล์มาตั้งแต่ตอนส่งงาน หรือบอกว่า "เลือกให้เลย" ระบบจะไม่ถาม ถ้าไม่สนใจเลือก ใช้ **มาตรฐาน**
   - ปรับบางค่าได้ เช่น "มาตรฐาน แต่ตัดตรง" สไตล์ที่เลือกบันทึกไว้ใน `brief.md` ตัดใหม่ทีหลังใช้แบบเดิม
3. **agent `brief` วิเคราะห์ภาพและเตรียมบรีฟ**: วิเคราะห์ทุกภาพก่อน (`scripts/photo_analysis.py`): แยกหมวด ภายนอก ภายใน ห้องนอน ห้องน้ำ ห้องครัว พื้นที่รอบบ้าน ให้คะแนนความสวยและความเหมาะสม เลือก Hero Shot ให้อัตโนมัติ หาที่ว่างวางข้อความ และกำหนดจุดซูมกับการเคลื่อนกล้อง ได้ภาพรวม `output/analysis/photo_analysis.jpg` แล้วเขียน `listings/<ทรัพย์>/brief.md` ตามสไตล์ที่เลือก director ตรวจข้อเท็จจริงกับประกาศอีกรอบ
4. **treatment และ storyboard**: director จะแสดง hook 3 วินาทีแรก จุดขายเรียงตามความแรง ไทม์ไลน์ 30 วินาที shot list (ความยาวและจังหวะเร็ว/ช้าทุกช็อต) ข้อความบนจอ สคริปต์เสียงพากย์ end card เพลง (จาก assets ถ้ามี ไม่มีก็ใช้เพลงประจำสไตล์ใน `brand/music/`) และภาพ storyboard ของทุกช็อต (`output/storyboard/storyboard.jpg`) ระบบจะรอเราตอบเฉพาะเมื่อมีข้อมูลขาดหรือขัดกัน นอกนั้นจะทำวิดีโอต่อเลยด้วยขั้นตอนที่ไม่ใช้เครดิต งานที่ใช้เครดิต Magnific (แต่งรูปด้วย AI, upscale, คลิป AI) จะเสนอพร้อมราคาไว้ให้เลือกเพิ่ม และทำเมื่อเราตกลงเท่านั้น ถ้าอยากเปลี่ยนอะไรหรืออยากใช้ไฟล์เสียงที่อัดเองแทนเสียง Kanya ก็บอกได้ตลอด
5. **แต่งรูป** (ถ้าต้องการ): director เสนอว่ารูปไหนควรแต่งอะไร พร้อมราคาเครดิตสำหรับงาน AI เมื่อเราตกลงแล้ว agent `retouch` จะแต่งรูปไว้ใน `output/retouched/` แล้ว director ตรวจทุกรูปเทียบกับต้นฉบับ
6. **ทำเสียงพากย์** (ทุกวิดีโอ): agent `voice-kanya` ใช้ `scripts/voiceover.py` ทำ `voiceover.wav` ด้วยเสียง Kanya: แปลงตัวเลขและตัวย่อเป็นคำอ่านให้เอง (5.5 ล้านบาท → ห้าจุดห้าล้านบาท, ตร.ม. → ตารางเมตร) ฟิตแต่ละประโยคให้พอดีช็อต และบอกเวลาของทุกวลีใน `voice/timing.json` แล้ว director ตั้ง caption ข้อความบนจอ และจุดตัดให้ตรงกับเสียง ส่วน editor มิกซ์ด้วย `scripts/mix_audio.py`: เพลงหลบลงใต้เสียงพากย์ 12–18 dB ทั้งคลิปดัง −14 LUFS ตามที่ Reels/TikTok/Shorts เล่น เพลงทุกเพลงต้องอยู่ใน `brand/music/LICENSES.md` (ทะเบียนสิทธิ์) ถ้าอยากเปลี่ยนไปใช้ Thai TTS API เจ้าอื่นในอนาคต เพิ่มเป็น engine ใน `scripts/voiceover.py` ได้
7. **คลิป AI จาก Magnific** (ถ้าต้องการ): director เสนอว่าช็อตไหนควรใช้คลิป AI พร้อมราคาเครดิต เมื่อเราตกลงช็อตและงบแล้ว agent `editor-magnific` จะทำคลิปไว้ใน `output/magnific/` ช็อตที่ไม่ผ่านการตรวจจะกลับไปใช้รูปแบบ Ken Burns
8. **QC, Preview แล้วตัดต่อ**: ก่อนส่ง preview ระบบตรวจคุณภาพด้วย `scripts/qc.py`: คำสะกด (ตาม `SPELLING.md` ใช้คำที่ตลาดใช้ เช่น บิ้วอิน ลิฟท์) ราคาและตัวเลขตรงประกาศ รายการ ✗ ไม่โผล่ในคลิป ข้อความไม่ทับจุดเด่นของภาพและอยู่ในเขตปลอดภัย ครอปไม่ผิดตำแหน่ง เสียงดังพอดีและตรงจังหวะภาพ ได้รายงาน `output/qc/qc.md` กับภาพ `qc_sheet.jpg` แล้ว director อ่านตรวจคำสะกดทุกบรรทัดเองอีกรอบ จากนั้น editor ทำ preview ครึ่งขนาด (มีป้าย PREVIEW และเสียงจริง) ใน `output/preview/` ก่อนเสมอ director ส่งให้ดูแล้ว**รอเราอนุมัติ** จากนั้นจึงเรนเดอร์ฉบับเต็มด้วย `scripts/render_cut.py` (HyperFrames + FFmpeg, MP4 H.264 High, 30 fps, AAC, ตรวจสเปกก่อนส่งทุกไฟล์) ถ้าอยากได้ 16:9 (YouTube, Facebook feed) หรือ 1:1 (feed) บอกได้ ระบบจัดเลย์เอาต์ใหม่ตามสัดส่วน agent `editor` สร้างวิดีโอใน `listings/<ทรัพย์>/output/` พร้อม `build.sh` ไว้สร้างซ้ำได้ และโปรเจกต์ HyperFrames ใน `output/hyperframes/index.html` ที่เปิดแก้ข้อความหรือจังหวะเองได้ในแอป HyperFrames ได้วิดีโอไฟล์เดียวแบบมีเพลง ถ้าอยากใส่เพลงเทรนด์ในแอป TikTok เอง ขอเวอร์ชันไม่มีเพลง (`_nomusic.mp4`) เพิ่มได้ โลโก้ Uptown Assets ในทุกวิดีโอเคลื่อนไหว: มุมซ้ายบนเด้งขึ้นตอนเริ่มแล้วมีแสงวิ้งผ่านตัว U เป็นระยะ ส่วน end card โลโก้ประกอบตัวขึ้นมา (วงแหวนวาดรอบ ตัว U ลอยขึ้น ชื่อขึ้นทีละบรรทัด) ไฟล์อยู่ใน `brand/logo_anim/` และมี `brand/logo_anim.mov` (พื้นใส) ไว้ใช้กับโปรแกรมตัดต่ออื่น ข้อความบนจอก็เคลื่อนไหวตามสไตล์ (เช่น มาตรฐานคำเลื่อนขึ้นทีละคำ เรียบหรูโผล่ขึ้นช้า ๆ พร้อมเส้นทอง เดินชมห้องเด้งแบบสติกเกอร์) ตัวเลขราคาเด้งขึ้นที่ค่าจริงเลย ไม่วิ่งตัวเลข ดูรายละเอียดใน `brand/text_fx/` Motion graphics อยู่ใน `brand/motion_fx/`: ฟอนต์หัวข้อ Kanit คู่ Sarabun, Price Highlight แผ่นทองมีประกาย, ไอคอนคุณสมบัติ (Lucide ใน `brand/icons/`) ที่วาดเส้นขึ้นมาเอง, parallax ชั้นกราฟิก, ไม่เกิน 2 ประเด็นต่อฉาก และข้อความทุกชิ้นอยู่ในเขตที่ TikTok, Reels และ Shorts ไม่มีปุ่มทับ (y 380–1248, x 120–780/888) ดูตัวอย่างใน `brand/motion_fx/motion_fx_preview.mp4` ทรานสิชันก็ต่างกันตามสไตล์ (whip pan, ซูมทะลุ, จางผ่านสีครีม, light leak, แฟลชอุ่น, สไลด์ในกรอบ) ไม่มีแบบที่ทำให้ภาพทรัพย์บิดเบี้ยว และจุดตัดลงบีตเพลงตามไฟล์ `brand/music/*.beats.json` (สร้างด้วย `scripts/music_beats.py`) ดูรายละเอียดใน `brand/transition_fx/`
9. **ตรวจและแก้**: director ตรวจไฟล์ (ความยาว ความละเอียด เสียง ข้อความอ่านออก) แล้วรายงาน ถ้าต้องแก้ก็สั่งตัดใหม่ได้

## โครงสร้างโฟลเดอร์ทรัพย์

```
listings/
  <รหัส>-<ชื่อทรัพย์>/
    assets/      รูป คลิป โลโก้ เพลง (ต้นฉบับ ระบบจะไม่แก้หรือลบ)
    brief.md     บรีฟจาก agent brief
    output/      วิดีโอที่ตัดเสร็จ, build.sh, voiceover.wav, voice/, magnific/, retouched/
```

ทุกอย่างใน `listings/` ถูกตั้งไว้ใน [listings/.gitignore](listings/.gitignore) ให้ไม่เข้า git (รวมถึง `brief.md` และวิดีโอที่ตัดเสร็จ) ต้องสำรองไฟล์เอง ทรัพย์ที่มีในเครื่องตอนนี้คือ `4269-manor-sanambinnam` และ `445-land-bang-yai`

## กฎที่ระบบยึด

- **ข้อเท็จจริงมาจากประกาศเท่านั้น**: ไม่แต่งราคา ขนาด หรือจุดเด่นเพิ่ม และไม่อ้างวิว ทิศ หรือสถานีใกล้เคียงถ้าประกาศไม่ได้ระบุ
- **สิ่งอำนวยความสะดวก**: ถ้าประกาศติ๊ก ✓ ส่วนกลางไว้ (สระว่ายน้ำ ฟิตเนส ฯลฯ) วิดีโอจะโชว์ด้วย: รูปส่วนกลางจริงพร้อมชื่อ (ถ้ามีรูป) แล้วการ์ด "ส่วนกลาง" ไม่เกิน 6 อย่าง ใช้เฉพาะรายการที่มี ✓ เท่านั้น รายการ ✗ คือไม่มี
- **สถานที่สำคัญใกล้เคียง**: ถ้าประกาศมีรายการสถานีหรือสถานที่ใกล้เคียง วิดีโอจะมีการ์ด "ใกล้" ก่อน end card แสดงไม่เกิน 4 แห่ง พร้อมระยะทางตามประกาศ (ไม่ใช้ภาพแผนที่หรือรูปของสถานที่นั้น)
- **แต่งรูปเพื่อความสวยงามได้ ไม่ต้องติดป้าย**: ปรับแสงและสี ลบของรกหรือของใช้ส่วนตัว จัดเฟอร์นิเจอร์เสมือนในห้องว่าง เปลี่ยนท้องฟ้าให้สดใส และใช้ภาพ render หรือห้องตัวอย่างได้เมื่อเราอนุมัติสำหรับทรัพย์นั้น
- **ห้ามบิดเบือนตัวทรัพย์**: ไม่ซ่อนตำหนิ (รอยร้าว คราบ รอยรั่ว ความเสียหาย) ไม่ทำให้ห้องหรือที่ดินดูใหญ่กว่าจริง ไม่ใส่วิวหรือสิ่งอำนวยความสะดวกที่ไม่มีจริง และไม่ลบสิ่งที่มีอยู่จริงรอบทรัพย์ (เสาไฟ สายไฟ ตึกข้างเคียง ถนน)
- **ข้อความบนจอเป็นภาษาไทย**: ราคาเขียนแบบ "5.5 ล้านบาท" พื้นที่ใช้ "ตร.ม." เบอร์โทรใช้รูปแบบ 0XX-XXX-XXXX และใช้คำว่า "รหัสทรัพย์"
- **Fair housing**: บรรยายตัวทรัพย์ ไม่ระบุว่าใครควรอยู่
- **ลิขสิทธิ์**: ใช้เฉพาะเพลง รูป และฟุตเทจที่มีสิทธิ์ใช้ ถ้าไม่ชัด (เช่นภาพหน้าจอ Google Maps) ระบบจะแจ้งก่อน
- **Caption ฝังในวิดีโอเสมอ** เพราะคนดูจำนวนมากปิดเสียง

## ปลั๊กอินของโปรเจกต์

โปรเจกต์มี marketplace ของตัวเองชื่อ `uptown-assets` อยู่ใน `.claude-plugin/marketplace.json` มีปลั๊กอิน 2 ตัว

| ปลั๊กอิน | หน้าที่ |
|---|---|
| **session-role** | ให้แต่ละเซสชันมี Role (หน้าที่ของ Claude) เลือกได้จาก dropdown เหนือช่องแชท หรือพิมพ์ `/role <ชื่อ>` แสดงสถานะการทำงานและ subagent ที่กำลังทำงาน ปุ่ม **↻** หน้าคำว่า Role ใช้โหลดรายการ role และ subagent ใหม่ |
| **video-list** | ปุ่ม **🎬 วีดีโอทั้งหมด** ท้ายบรรทัด Role (ถ้าไม่มี session-role จะขึ้นเป็นบรรทัดของตัวเอง) กดแล้วเปิดแผงด้านข้าง แสดงวิดีโอใน `listings/*/output/` แยกตามทรัพย์ พร้อมความยาว ขนาด วันที่ และปุ่ม **เปิด** / **Finder** พิมพ์ `/videos` ก็เปิดได้ |

`session-role` ก๊อปมาจาก [MrLudy-BxB/shanti-roles](https://github.com/MrLudy-BxB/shanti-roles) (เวอร์ชัน 0.7.0) แล้วแก้เป็น 0.7.1: ย้ายปุ่ม ↻ จากท้ายบรรทัดมาไว้หน้าคำว่า Role ถ้าจะอัปเดตจากต้นฉบับ ให้ก๊อปมาทับแล้วย้าย ↻ อีกครั้ง

ติดตั้ง (ทำครั้งเดียวต่อเครื่อง หลัง clone โปรเจกต์แล้ว) ให้รันในโฟลเดอร์โปรเจกต์:

```bash
cd uptown_assets
claude plugin marketplace add "$PWD" --scope local
claude plugin install session-role@uptown-assets --scope local
claude plugin install video-list@uptown-assets --scope local
```

ถ้าเครื่องนั้นเคยติดตั้ง `session-role@shanti-roles` จากต้นฉบับไว้แล้ว ให้ปิดตัวนั้นเฉพาะในโปรเจกต์นี้ด้วย ไม่งั้นจะมีแถบ Role ซ้อนกัน 2 แถว (โปรเจกต์อื่นยังใช้ตัวต้นฉบับได้ตามเดิม):

```bash
claude plugin disable session-role@shanti-roles --scope local
```

แล้วเปิดเซสชันใหม่ในโปรเจกต์นี้ แถบ Role และปุ่มจะขึ้นเหนือช่องแชท

- ติดตั้งแบบ `local` คือใช้เฉพาะโปรเจกต์นี้บนเครื่องนั้น ค่าตั้งอยู่ใน `.claude/settings.local.json` ซึ่งไม่ขึ้น git
- ปลั๊กอินอ่านไฟล์จากโฟลเดอร์ `session-role/` และ `video-list/` ของโปรเจกต์โดยตรง หลัง `git pull` ได้เวอร์ชันใหม่ ให้เปิดเซสชันใหม่ก็พอ
- video-list ต้องใช้ macOS (คำสั่ง `open`) และ `ffprobe` สำหรับอ่านความยาววิดีโอ
- ต้องมีคำสั่ง `claude` ในเทอร์มินัล ถ้าใช้แต่แอปเดสก์ท็อป ให้ติดตั้ง Claude Code CLI ก่อน

รายละเอียดของ session-role อยู่ใน [session-role/README.md](session-role/README.md) และ [session-role/ARCHITECTURE.md](session-role/ARCHITECTURE.md)

```
.claude-plugin/marketplace.json   แคตตาล็อกปลั๊กอิน (marketplace "uptown-assets")
session-role/                     ปลั๊กอิน role, ตัวเลือก role, ขอบเขตการแก้ไฟล์, ตัวแสดง subagent
video-list/                       ปลั๊กอินปุ่ม "วีดีโอทั้งหมด" เหนือช่องแชท เปิดรายการวิดีโอที่ตัดเสร็จ
export.py                         เครื่องมือสำหรับ export ปลั๊กอินจากโฟลเดอร์ dev
```
