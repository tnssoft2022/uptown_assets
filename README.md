# Uptown Assets: ระบบทำวิดีโอ TikTok สำหรับอสังหาริมทรัพย์

ระบบนี้ใช้ Claude Code ทำวิดีโอแนวตั้ง (9:16) สำหรับโพสต์ขายหรือเช่าทรัพย์บน TikTok ตั้งแต่อ่านข้อมูลประกาศ วางเรื่อง ทำเสียงพากย์ ไปจนถึงตัดต่อเป็นไฟล์ MP4 พร้อมโพสต์
งานแบ่งให้ AI หลายตัวทำตามหน้าที่ โดยมี **director** (ผู้กำกับ) เป็นตัวที่คุยกับเราและสั่งงานตัวอื่น

## ทีมงาน

| ชื่อ | ไฟล์ | หน้าที่ |
|---|---|---|
| **director** (role) | [.claude/roles/director.md](.claude/roles/director.md) | ผู้กำกับ เป็น role เริ่มต้นของโปรเจกต์ คุยกับเราเป็นภาษาไทย ถามข้อมูลที่ขาด วาง treatment และ shot list เขียน copy กับ caption สั่งงาน agent ด้านล่าง แล้วตรวจผลงานก่อนรายงาน |
| **brief** (agent) | [.claude/agents/brief.md](.claude/agents/brief.md) | อ่านข้อมูลประกาศ ตรวจรูปและคลิปทุกไฟล์ แยกตามห้อง ดึงข้อเท็จจริงของทรัพย์ แล้วเขียน `brief.md` (ความพร้อม, treatment ร่าง, สคริปต์เสียงพากย์, brief สำหรับ editor) |
| **retouch** (agent) | [.claude/agents/retouch.md](.claude/agents/retouch.md) | แต่งรูปก่อนทำวิดีโอ แบบฟรีด้วย ffmpeg (ดัดภาพเอียง ปรับแสงและสี ปรับโทนให้เข้ากัน ลดนอยส์ เบลอหน้าคนและป้ายทะเบียน) และแบบใช้เครดิต Magnific (ลบของรก จัดเฟอร์นิเจอร์เสมือน เปลี่ยนท้องฟ้า ขยายภาพ) ตรวจทุกรูปเทียบกับต้นฉบับ แล้วบันทึกไว้ใน `output/retouched/` พร้อมภาพเทียบก่อน/หลัง |
| **voice-kanya** (agent) | [.claude/agents/voice-kanya.md](.claude/agents/voice-kanya.md) | ทำเสียงพากย์ภาษาไทยด้วยเสียง Kanya ของ macOS (`say`) ทำงานบนเครื่องทั้งหมด ฟรี แต่เสียงจะออกแนวหุ่นยนต์ ได้ไฟล์ `voiceover.wav` ที่ตรงกับไทม์ไลน์วิดีโอ |
| **editor-magnific** (agent) | [.claude/agents/editor-magnific.md](.claude/agents/editor-magnific.md) | ขยายภาพให้คมขึ้น (Magnific Precision) แล้วเปลี่ยนรูปเป็นคลิปเคลื่อนไหวด้วย AI ของ Magnific (image-to-video เช่น Kling) ประเมินเครดิตก่อนและใช้ไม่เกินงบที่ director ให้ ตรวจภาพที่ขยายและทุกคลิปเทียบกับรูปต้นฉบับว่าไม่มีของงอก หาย หรือบิดเบี้ยว แล้วดาวน์โหลดมาไว้ให้ editor ตัดต่อ (ไม่ได้ตัดวิดีโอฉบับสุดท้ายเอง) |
| **editor** (agent) | [.claude/agents/editor.md](.claude/agents/editor.md) | ตัดต่อด้วย ffmpeg ทำเฉพาะวิดีโอ TikTok (1080×1920, 20–30 วินาที, ไม่เกิน 60) ใส่ Ken Burns, caption, เพลง และ end card แล้วตรวจไฟล์ก่อนส่ง |

## ขั้นตอนการทำวิดีโอ

1. **ส่งข้อมูลทรัพย์**: เปิดเซสชันในโปรเจกต์นี้ (role `director` ถูกเลือกให้อัตโนมัติ) แล้วส่งลิงก์ประกาศ uptownassets.com หรือส่งข้อความประกาศกับรูปและคลิปของเราเอง ระบบจะสร้างโฟลเดอร์ `listings/<รหัส>-<ชื่อทรัพย์>/assets/` ให้
2. **agent `brief` เตรียมบรีฟ**: เขียน `listings/<ทรัพย์>/brief.md` แล้ว director ตรวจข้อเท็จจริงกับประกาศอีกรอบ
3. **treatment และ storyboard**: director จะแสดง hook วินาทีแรก ลำดับเรื่อง shot list ข้อความบนจอ สคริปต์เสียงพากย์ end card เพลง (ถ้ามีใน assets) และภาพ storyboard ของทุกช็อต (`output/storyboard/storyboard.jpg`) ระบบจะรอเราตอบเฉพาะเมื่อมีข้อมูลขาดหรือขัดกัน นอกนั้นจะทำวิดีโอต่อเลยด้วยขั้นตอนที่ไม่ใช้เครดิต งานที่ใช้เครดิต Magnific (แต่งรูปด้วย AI, upscale, คลิป AI) จะเสนอพร้อมราคาไว้ให้เลือกเพิ่ม และทำเมื่อเราตกลงเท่านั้น ถ้าอยากเปลี่ยนอะไรหรืออยากใช้ไฟล์เสียงที่อัดเองแทนเสียง Kanya ก็บอกได้ตลอด
4. **แต่งรูป** (ถ้าต้องการ): director เสนอว่ารูปไหนควรแต่งอะไร พร้อมราคาเครดิตสำหรับงาน AI เมื่อเราตกลงแล้ว agent `retouch` จะแต่งรูปไว้ใน `output/retouched/` แล้ว director ตรวจภาพเทียบก่อน/หลัง
5. **ทำเสียงพากย์** (ทุกวิดีโอ): agent `voice-kanya` ทำ `voiceover.wav` แล้ว director ตั้งเวลา caption ตามเสียง
6. **คลิป AI จาก Magnific** (ถ้าต้องการ): director เสนอว่าช็อตไหนควรใช้คลิป AI พร้อมราคาเครดิต เมื่อเราตกลงช็อตและงบแล้ว agent `editor-magnific` จะทำคลิปไว้ใน `output/magnific/` ช็อตที่ไม่ผ่านการตรวจจะกลับไปใช้รูปแบบ Ken Burns
7. **ตัดต่อ**: agent `editor` สร้างวิดีโอใน `listings/<ทรัพย์>/output/` พร้อม `build.sh` ไว้สร้างซ้ำได้ ถ้ามีเพลงจะได้ 2 เวอร์ชัน คือมีเพลงกับไม่มีเพลง (`_nomusic.mp4`) ไว้ใส่เพลงเทรนด์ในแอป TikTok เอง
8. **ตรวจและแก้**: director ตรวจไฟล์ (ความยาว ความละเอียด เสียง ข้อความอ่านออก) แล้วรายงาน ถ้าต้องแก้ก็สั่งตัดใหม่ได้

## โครงสร้างโฟลเดอร์ทรัพย์

```
listings/
  <รหัส>-<ชื่อทรัพย์>/
    assets/      รูป คลิป โลโก้ เพลง (ต้นฉบับ ระบบจะไม่แก้หรือลบ)
    brief.md     บรีฟจาก agent brief
    output/      วิดีโอที่ตัดเสร็จ, build.sh, voiceover.wav, voice/, magnific/, retouched/
```

ทุกอย่างใน `listings/` ถูกตั้งไว้ใน [listings/.gitignore](listings/.gitignore) ให้ไม่เข้า git (รวมถึง `brief.md` และวิดีโอที่ตัดเสร็จ) ต้องสำรองไฟล์เอง ทรัพย์ที่มีในเครื่องตอนนี้คือ `4269-manor-sanambinnam` และ `445-land-bang-yai`

## กฎที่ระบบยึด

- **ข้อเท็จจริงมาจากประกาศเท่านั้น**: ไม่แต่งราคา ขนาด หรือจุดเด่นเพิ่ม และไม่อ้างวิว ทิศ หรือสถานีใกล้เคียงถ้าประกาศไม่ได้ระบุ
- **แต่งรูปเพื่อความสวยงามได้ ไม่ต้องติดป้าย**: ปรับแสงและสี ลบของรกหรือของใช้ส่วนตัว จัดเฟอร์นิเจอร์เสมือนในห้องว่าง เปลี่ยนท้องฟ้าให้สดใส และใช้ภาพ render หรือห้องตัวอย่างได้เมื่อเราอนุมัติสำหรับทรัพย์นั้น
- **ห้ามบิดเบือนตัวทรัพย์**: ไม่ซ่อนตำหนิ (รอยร้าว คราบ รอยรั่ว ความเสียหาย) ไม่ทำให้ห้องหรือที่ดินดูใหญ่กว่าจริง ไม่ใส่วิวหรือสิ่งอำนวยความสะดวกที่ไม่มีจริง และไม่ลบสิ่งที่มีอยู่จริงรอบทรัพย์ (เสาไฟ สายไฟ ตึกข้างเคียง ถนน)
- **ข้อความบนจอเป็นภาษาไทย**: ราคาเขียนแบบ "5.5 ล้านบาท" พื้นที่ใช้ "ตร.ม." เบอร์โทรใช้รูปแบบ 0XX-XXX-XXXX และใช้คำว่า "รหัสทรัพย์"
- **Fair housing**: บรรยายตัวทรัพย์ ไม่ระบุว่าใครควรอยู่
- **ลิขสิทธิ์**: ใช้เฉพาะเพลง รูป และฟุตเทจที่มีสิทธิ์ใช้ ถ้าไม่ชัด (เช่นภาพหน้าจอ Google Maps) ระบบจะแจ้งก่อน
- **Caption ฝังในวิดีโอเสมอ** เพราะคนดูจำนวนมากปิดเสียง

## สิ่งที่ต้องมีในเครื่อง

- Claude Code (แอปเดสก์ท็อปหรือเทอร์มินัล) เวอร์ชัน 2.1.286 ขึ้นไป
- `ffmpeg` และ `ffprobe`
- macOS ที่มีเสียง Kanya (สำหรับเสียงพากย์ภาษาไทย)
- บัญชี Magnific แบบเสียเงินที่เชื่อมกับ Claude เป็น connector (เฉพาะถ้าจะใช้ agent `editor-magnific` หรืองาน AI ของ `retouch`)

## ปลั๊กอินของโปรเจกต์

โปรเจกต์มี marketplace ของตัวเองชื่อ `uptown-assets` อยู่ใน `.claude-plugin/marketplace.json` มีปลั๊กอิน 2 ตัว

| ปลั๊กอิน | หน้าที่ |
|---|---|
| **session-role** | ให้แต่ละเซสชันมี Role (หน้าที่ของ Claude) เลือกได้จาก dropdown เหนือช่องแชท หรือพิมพ์ `/role <ชื่อ>` แสดงสถานะการทำงานและ subagent ที่กำลังทำงาน ปุ่ม **↻** หน้าคำว่า Role ใช้โหลดรายการ role และ subagent ใหม่ |
| **video-list** | ปุ่ม **🎬 วีดีโอทั้งหมด** ท้ายบรรทัด Role (ถ้าไม่มี session-role จะขึ้นเป็นบรรทัดของตัวเอง) กดแล้วเปิดแผงด้านข้าง แสดงวิดีโอใน `listings/*/output/` แยกตามทรัพย์ พร้อมความยาว ขนาด วันที่ และปุ่ม **เปิด** / **Finder** พิมพ์ `/videos` ก็เปิดได้ |

`session-role` ก๊อปมาจาก [MrLudy-BxB/shanti-roles](https://github.com/MrLudy-BxB/shanti-roles) (เวอร์ชัน 0.7.0) แล้วแก้เป็น 0.7.1: ย้ายปุ่ม ↻ จากท้ายบรรทัดมาไว้หน้าคำว่า Role ถ้าจะอัปเดตจากต้นฉบับ ให้ก๊อปมาทับแล้วย้าย ↻ อีกครั้ง

ติดตั้ง (ทำครั้งเดียวต่อเครื่อง หลัง clone โปรเจกต์แล้ว) ให้รันในโฟลเดอร์โปรเจกต์:

```bash
cd uptown_assets
claude plugin marketplace add "$PWD" --scope local
claude plugin install session-role@uptown-assets --scope local
claude plugin install video-list@uptown-assets --scope local
```

ถ้าเครื่องนั้นเคยติดตั้ง `session-role@shanti-roles` จากต้นฉบับไว้แล้ว ให้ปิดตัวนั้นเฉพาะในโปรเจกต์นี้ด้วย ไม่งั้นจะมีแถบ Role ซ้อนกัน 2 แถว (โปรเจกต์อื่นยังใช้ตัวต้นฉบับได้ตามเดิม):

```bash
claude plugin disable session-role@shanti-roles --scope local
```

แล้วเปิดเซสชันใหม่ในโปรเจกต์นี้ แถบ Role และปุ่มจะขึ้นเหนือช่องแชท

- ติดตั้งแบบ `local` คือใช้เฉพาะโปรเจกต์นี้บนเครื่องนั้น ค่าตั้งอยู่ใน `.claude/settings.local.json` ซึ่งไม่ขึ้น git
- ปลั๊กอินอ่านไฟล์จากโฟลเดอร์ `session-role/` และ `video-list/` ของโปรเจกต์โดยตรง หลัง `git pull` ได้เวอร์ชันใหม่ ให้เปิดเซสชันใหม่ก็พอ
- video-list ต้องใช้ macOS (คำสั่ง `open`) และ `ffprobe` สำหรับอ่านความยาววิดีโอ
- ต้องมีคำสั่ง `claude` ในเทอร์มินัล ถ้าใช้แต่แอปเดสก์ท็อป ให้ติดตั้ง Claude Code CLI ก่อน

รายละเอียดของ session-role อยู่ใน [session-role/README.md](session-role/README.md) และ [session-role/ARCHITECTURE.md](session-role/ARCHITECTURE.md)

```
.claude-plugin/marketplace.json   แคตตาล็อกปลั๊กอิน (marketplace "uptown-assets")
session-role/                     ปลั๊กอิน role, ตัวเลือก role, ขอบเขตการแก้ไฟล์, ตัวแสดง subagent
video-list/                       ปลั๊กอินปุ่ม "วีดีโอทั้งหมด" เหนือช่องแชท เปิดรายการวิดีโอที่ตัดเสร็จ
export.py                         เครื่องมือสำหรับ export ปลั๊กอินจากโฟลเดอร์ dev
```
