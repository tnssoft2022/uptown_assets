# Feature icons

Line icons from Lucide (lucide-static 1.77.0, ISC licence in `LICENSE`, free for commercial use), copied
as they are. The `editor` pastes an icon's `<svg>` inline into the cut (drop the first comment line and the
`class` attribute) so `brand/motion_fx/motion_fx.js` can draw it and the CSS can colour it. Never redraw,
fill or recolour an icon beyond the CSS in `brand/motion_fx/typography.css`.

An icon only goes next to a fact the listing states: a ✓ item, a number from the listing, a nearby place
the listing names. No icon for a ✗ or unlisted item, and never an icon for who lives there.
